# Turtle Circle Pattern

A simple Python graphics project that uses the Turtle module to create a colorful circular pattern on a black background.

---

## Features

* Creates a circular pattern using Python Turtle
* Uses multiple colors
* Black background
* Smooth and fast drawing
* Generates 360 rotating circles

---

## Technologies

* Python
* Turtle Graphics

---

## Requirements

This project uses Python's built-in `turtle` module, so no external libraries are required.

---

## Run

Run the program with:

```bash
Fiery sun burst design.py
```

---

## How It Works

The program creates a Turtle object and draws a circle 360 times.

After each circle, the Turtle rotates one degree to create the final circular pattern. The color changes every five circles using a predefined color list.
